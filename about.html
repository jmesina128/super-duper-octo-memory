About Me

I'm a sophomore at the University of Maryland, Baltimore County (UMBC) transitioning from Information Systems into a B.A. in Business Technology Administration (BTA).

My focus sits at the intersection of business operations, e-commerce, and technical system design. Whether I'm building interactive browser applications, modeling relational databases, or managing high-volume logistics workflows, I enjoy turning messy real-world requirements into clean, structured systems.

Outside of classes, I build custom web games and interactive prototypes, analyze strategy in chess and poker, and work on small-scale jewelry crafting and online reselling.

My IS 202 Learning Journey

1. SDLC & Wireframing First

IS 202 shifted how I start projects. Instead of jumping straight into code, I now begin with requirements analysis, sitemaps, and low-fidelity wireframes to validate layout and user flow early.

2. System Design & Databases

Learned how to break applications into modular components and structure data cleanly using Third Normal Form (3NF) Entity-Relationship Diagrams to eliminate redundancy.

3. Containerization with Docker

Gained hands-on experience packaging applications and dependencies inside Docker containers so code runs identically across local machines and deployment servers.

4. UI/UX Principles & Git Workflows

Applied visual hierarchy, responsive Bootstrap grids, color contrast, and semantic HTML alongside structured Git commits and GitHub Pages publishing.
